# Basic Compilers
Currently learning about Compilers and Interpters. This is a collection of code I will be working on and testing. The aim to build a simple compiler and interpreter for a simple language.

This Project consist of two compilers
1. [Phlox](https://github.com/phlox-lang/phlox) - A PHP implementation of the [Crafting Interpreters](http://craftinginterpreters.com/) book.
2. [Cplox](https://github.com/cplox/cplox) - A C++ implementation of the [Crafting Interpreters](http://craftinginterpreters.com/) book.
